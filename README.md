# База данных высот микрорельефа ДОЭ (PostgreSQL)

Настоящий проект реализован на практических данных, полученных в ходе создания матричного гиперспектрометра на основе матриц гармонических линз, а именно, измеренных высотах микрорельефа гармонических линз. Исходные данные о высотах хранились в Excel-таблице, и были перенесены в реляционную базу PostgreSQL, в дальнейшем они были проанализированы с использованием SQL-запросов.

## Данные

Исходные данные - файл DOE_heights.xlsx, содержит 10 листов, каждый лист - одно измерение одного образца (образец S_NEX измерен дважды). Для каждого образца было выполнено 16 измерений, т.к. матрица гармонических линз 4x4. Всего 160 значений высот в мкм. Для дальнейшей загрузки в PostgreSQL и анализа данных файл .xlsx был переведен в "плоский" файл .csv.

## Структура базы данных (схема 'doe')

- 'sample' - образцы;
- 'measurement' - измерения (дата измерения, метка образца, лист Excel);
- 'lens' - 16 линз и их расположение в сетке (расположение важно для проектирования гиперспектрометра);
- 'lens_height' - высота линзы (составной первичный ключ: измерение + линза)

## Файлы

| Файл | Назначение                                     |
|---|------------------------------------------------|
| `export_to_csv.py` | Excel → CSV: собирает 10 листов в одну таблицу |
| `01_schema.sql` | создание схемы и таблиц                        |
| `02_load.sql` | загрузка CSV через промежуточную таблицу       |
| `03_queries.sql` | аналитические запросы                          |

## Как запустить

```bash
pip install -r requirements.txt
python export_to_csv.py
```

В psql (из папки проекта, база `doe_lab`):
```
\i 01_schema.sql
\i 02_load.sql
\i 03_queries.sql
```

## Содержание запросов

1. JOIN и выборка 
2. Агрегатные функции: расчет среднего, min/max, медианы, СКО, HAVING
3. Подзапросы и CTE
4. Оконные функции

## Использумые технологии
